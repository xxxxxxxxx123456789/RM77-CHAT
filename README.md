# RM77 CHAT v2.0

RM77 CHAT is a lightweight terminal-based group chat application designed for fast and simple communication between friends.

Features:
- Custom nicknames
- Multiple chat colors
- Host or join rooms
- Private messaging (whispers)
- Real-time communication
- Unique RM77 room-code system

Usage:
1. Enter your nickname.
2. Choose your chat color.
3. Host a room or join an existing one.
4. Start chatting instantly.
